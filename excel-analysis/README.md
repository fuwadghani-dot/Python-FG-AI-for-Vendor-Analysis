# Excel Analysis (Streamlit + Pandas)

Simple scaffold to load, clean, analyze, visualize, and export Excel data via a Streamlit web UI.

## Quick start

1. Create virtualenv and activate it:

```bash
python -m venv .venv
source .venv/bin/activate
```

2. Install dependencies:

```bash
pip install -r requirements.txt
```

3. Run the Streamlit app:

```bash
streamlit run app.py
```

4. Drop sample files into `data_samples/` and upload them through the UI.

---

See `src/excel_analysis` for core modules and `tests/` for basic tests.
